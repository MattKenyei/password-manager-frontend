# Password Manager — Frontend

Zero-knowledge password manager. One Vue 3 codebase, four platforms: web, desktop (Tauri), browser extension (Chrome MV3), and Android (Capacitor).

Server never sees your master password or decrypted data.

**Live demo:** https://password-manager-6y7.pages.dev
**Backend:** https://github.com/MattKenyei/password-manager-backend
**API docs:** https://github.com/MattKenyei/password-manager-backend/blob/dev/docs/API.md

## Platforms

| Platform  | Command                 | Runs on                                              |
| --------- | ----------------------- | ---------------------------------------------------- |
| Web       | `npm run dev`           | `http://localhost:5173`                              |
| Desktop   | `npm run tauri dev`     | Native window (Tauri v2)                             |
| Extension | `npm run dev:extension` | `chrome://extensions` → load `dist-extension/`       |
| Android   | `npm run build:mobile`  | Build APK → `adb install` (no Android Studio needed) |

Each platform shares `src/` (crypto, api, db, views). Platform-specific code lives in `src/platform/` and `src/extension/`.

## Stack

- **Vue 3** (Composition API) + TypeScript
- **Pinia** + **Vue Router**
- **Axios**
- **Tailwind CSS** v4 + **SCSS**
- **Dexie** (IndexedDB) — local encrypted cache
- **WebCrypto** (AES-256-GCM, HKDF) — item encryption
- **hash-wasm** (Argon2id) — key derivation
- **zxcvbn-ts** — password strength
- **Tauri v2** — desktop
- **CRXJS** — browser extension
- **Capacitor** — Android
- **@aparajita/capacitor-secure-storage** — Android Keystore
- **@aparajita/capacitor-biometric-auth** — fingerprint / face unlock

### Load extension in Chrome

1. `chrome://extensions` → enable Developer mode
2. **Load unpacked** → select `dist-extension/`
3. Reload the card after each rebuild (or use `dev:extension` for HMR)

### Build Android APK (no Android Studio)

Prerequisites: **JDK 21**, **Android SDK command-line tools**, `adb` in PATH.

```bash
# 1. Build frontend with mobile env
# .env.mobile contains VITE_API_URL=https://your-backend.onrender.com
npm run build:mobile

# 2. Sync to Android project
npx cap sync android

# 3. Build APK
cd android
./gradlew assembleDebug

# 4. Install on connected device
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

APK path: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Security model

**Client-side crypto**

- `master_key = Argon2id(master_password, enc_salt)`
- `account_key` — random 32 bytes, wrapped with `master_key`
- Each item encrypted with `HKDF(account_key, item_id)` + AES-256-GCM

**Key storage per platform**

| Platform  | `account_key`                                            | Refresh token                         |
| --------- | -------------------------------------------------------- | ------------------------------------- |
| Web       | In-memory tab (lost on reload)                           | `localStorage` (if "remember device") |
| Desktop   | In-memory + OS keychain (optional)                       | OS keychain / `localStorage`          |
| Extension | `chrome.storage.session` (in-memory)                     | `chrome.storage.local`                |
| Android   | In-memory + Android Keystore (optional biometric unlock) | `localStorage`                        |

`account_key` is **never** written to disk in plaintext.

**Android biometric unlock:** the raw `account_key` is stored in Android Keystore (encrypted by OS, requires unlocked device). Biometric prompt is enforced in-app before reading. Same approach as 1Password/Bitwarden mobile.

## Extension architecture

```
Popup ──chrome.runtime.sendMessage──▶ Service Worker ──fetch──▶ Backend
Content script ─────────────────────────┘
```

- SW is the only place with `account_key` and tokens
- Popup derives keys, sends `account_key` to SW, SW persists to `storage.session`
- Content script asks SW for credentials by URL, fills fields via native events
- Standalone: no Tauri required

## Android architecture

```
Vue app (WebView, https://localhost)
    │
    ├─ crypto → WebCrypto (same as web)
    ├─ db → Dexie (IndexedDB)
    ├─ api → fetch to https://your-backend.onrender.com
    │
    └─ @capacitor/* plugins
        ├─ SecureStorage → Android Keystore (account_key)
        ├─ BiometricAuth → fingerprint prompt
        └─ App → appStateChange (lock on background)
```

- Same Vue code as web, no platform-specific views
- `isCapacitor()` / `isAndroid()` in `src/platform/env.ts` gate native plugins
- Vault locks on `appStateChange` (background) — unlock requires fingerprint or master password
